# 🚗 Car Rental and Selling Management System

A web-based platform for managing car rentals and vehicle sales efficiently.
Allows users to browse available cars, rent vehicles, and purchase cars online.
Provides administrators with tools to manage vehicles, customers, bookings, and sales.
Features a user-friendly interface designed for a smooth and convenient experience.
Built to simplify car rental and selling operations through a centralized management system.
